# Bitcoin Knots coinbase-maturity PRs: a plain-language guide

**Live guide: https://geobees.github.io/xbt-coinbase-maturity-prs/**

A single-page, neutral guide to the open pull requests about coinbase maturity in Bitcoin Knots (XBT / BIP-110). Newly mined coins can't be spent for a set number of blocks, and these PRs propose different rules for how long that wait is and when it changes.

The guide covers:
- what each PR does, who proposed it, and its current status
- test results and review votes
- a calculator showing when coins unlock under each option

It is informational only. It does not endorse any PR, and figures are based on public PR discussion and local test runs at the commit hashes shown. Always check the PR itself for the latest state.

Last updated: 23 Oct 2026. Testing by Geobees-Veloni.
